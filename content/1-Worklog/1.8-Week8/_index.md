### Week 8 Objectives:

- Practice AWS monitoring and security solutions.
- Learn IAM authorization and security mechanisms for AWS Lambda.
- Study resource management using Tags and Resource Groups.
- Explore the AWS database ecosystem.
- Strengthen knowledge of cloud database services and data management.

### Tasks to be carried out this week:

| Day | Task | Start Date | Completion Date | Reference Material |
| --- | ---- | ---------- | --------------- | ------------------ |
| 2 | - Practice Lab 18: AWS Security Hub <br> - Enable AWS Security Hub and assess the security posture of the AWS environment <br> - Analyze Security Findings and AWS Security Best Practices | 06/08/2026 | 06/08/2026 | https://cloudjourney.awsstudygroup.com/ |
| 3 | - Practice Lab 22: Security Group and IAM Role for AWS Lambda <br> - Configure IAM Roles following the Principle of Least Privilege <br> - Test Lambda execution and verify CloudWatch Logs | 06/09/2026 | 06/09/2026 | https://cloudjourney.awsstudygroup.com/ |
| 4 | - Practice Lab 27: Resource Tagging and Resource Groups <br> - Manage AWS resources using Tags, AWS CLI, and Resource Groups <br> - Clean up AWS resources after completing the lab | 06/10/2026 | 06/10/2026 | https://cloudjourney.awsstudygroup.com/ |
| 5 | - Study Module 06: Database Services <br> - Learn Amazon RDS, Amazon Aurora, Amazon Redshift, and Amazon ElastiCache <br> - Study OLTP, OLAP, Primary Key, Foreign Key, and Index concepts | 06/11/2026 | 06/11/2026 | https://cloudjourney.awsstudygroup.com/ |
| 6 | - Review the knowledge from Modules 05 and 06 <br> - Summarize AWS security, resource management, and database services <br> - Complete the Week 8 practice report | 06/12/2026 | 06/12/2026 | https://cloudjourney.awsstudygroup.com/ |

### Week 8 Achievements:

| Day | Task | Achievement |
| --- | ---- | ----------- |
| 2 | AWS Security Hub Practice | Successfully enabled AWS Security Hub, analyzed Security Findings, and understood how AWS Security Best Practices are used to evaluate the security posture of cloud resources. |
| 3 | AWS Lambda Security | Learned how to secure AWS Lambda by configuring IAM Roles based on the Principle of Least Privilege and applying appropriate Security Group rules for serverless applications. |

| 6 | Knowledge Review | Consolidated knowledge of AWS security, resource management, and cloud database services, completed the Week 8 report, and prepared for the upcoming learning modules. |
