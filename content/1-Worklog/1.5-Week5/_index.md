### Week 5 Objectives:

- Study the architecture and advanced Amazon EC2 instance types.
- Learn about AWS storage and backup services.
- Practice deploying AWS Backup and the data recovery process.
- Prepare foundational knowledge of Amazon S3 Advanced Features for upcoming labs.

### Tasks for This Week:

| Day | Tasks | Start Date | Completion Date | Reference |
| --- | --- | --- | --- | --- |
| Monday | - Study Amazon EC2 Instance Types <br> - Learn about Intel, AMD, and AWS Graviton CPU architectures | 18/05/2026 | 18/05/2026 | AWS Skill Builder / AWS Documentation |
| Tuesday | - Learn about Amazon EBS Volumes and Instance Store <br> - Study EC2 User Data and Instance Metadata | 19/05/2026 | 19/05/2026 | AWS Skill Builder / AWS Documentation |
| Wednesday | - Study Auto Scaling and Elastic Load Balancing <br> - Learn about Amazon EFS and Amazon FSx | 20/05/2026 | 20/05/2026 | AWS Skill Builder / AWS Documentation |
| Thursday | - Practice **Lab 13: Deploy AWS Backup to the System** <br> - Create a Backup Plan, Backup Vault, and perform a Restore Test | 21/05/2026 | 21/05/2026 | First Cloud AI Journey Course |
| Friday | - Study Amazon S3 Advanced Features <br> - Learn about Static Website Hosting, Versioning, CloudFront, and Cross-Region Replication | 22/05/2026 | 22/05/2026 | Amazon S3 Documentation |
| Saturday | - Attend the **AWS First Cloud AI Journey Community Day** <br> - Listen to AWS experts' presentations and connect with the cloud community | 23/05/2026 | 23/05/2026 | AWS First Cloud AI Journey Community |
