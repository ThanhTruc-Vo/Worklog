### Week 1 Objectives:

- Attend the AWS First Cloud AI Journey Kickoff to understand the program regulations, working culture, and connect with members of the First Cloud Journey technical community.
- Successfully create a personal AWS account by configuring billing information and budget management (AWS Free Tier) for learning and hands-on practice, while becoming familiar with the AWS Management Console and AWS CLI.
- Complete the required AWS Console tasks to receive a total of **USD 200 AWS Credits**, helping reduce costs when using paid AWS services.
- Study the fundamentals of AWS, including core service categories (Compute, Storage, Networking, Database, etc.), AWS architecture, and the AWS pricing model to prepare for future cloud deployments.
